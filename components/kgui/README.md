kgui
====

kodeOS's own interface: AO_Gui and its screens, the clock face where Kody lives, the launcher, the settings and the sheets. It is built on the SDK like any app and starts after kode_init().

Depends on: kode_sys, kaos, kui, kbsp, kdrv, LVGL

Docs: https://docs.kode.diy/internals/gui/overview
