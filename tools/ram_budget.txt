# kodeOS's budget of internal RAM, read by sdk/tools/check_ram.sh:
#
#   sdk/tools/check_ram.sh build/kodeos.elf tools/ram_budget.txt
#
# The ESP32-P4 has 640 KB of internal RAM (655,360 bytes). What the image
# takes of it at link time - code in IRAM, .data and .bss - is what the heap
# does not get at boot, and DMA buffers and task stacks have nowhere else to
# come from.
#
# static_max is the ceiling of that static image. It sits a few kilobytes
# above what kodeOS takes, on purpose: a change that needs more either moves
# something to PSRAM or raises this number in the same commit, where a
# reviewer sees it.
#
# With CONFIG_KODE_LOWPOWER on, which kodeOS turns on in sdkconfig.defaults,
# the static image is 19,016 bytes larger (391,232 off, 410,248 on): 13,030
# of IRAM for the power-management and sleep code, which light sleep runs with
# the flash cache off, and about 6 KB of data for AO_LowPower (its 3,072-byte
# stack, listed below), the radio's sentinel and the sleep tables. The
# ceiling is that figure and a few kilobytes.
#
# AO_Scheduler adds its 3,072-byte stack (listed below), its queue and the
# wider large event pool (16,512 bytes: an entry of the scheduler carries a
# name, an expression and a console line), and the static image reads 414,424.
static_max 417000

# stack of a task that writes flash, memory an interrupt reads, a table a
